Acerca de REATS

REATS es una aplicación web que permite administrar un menú de platillos utilizando Firebase Firestore como base de datos en tiempo real.

Los usuarios pueden agregar nuevos platillos y realizar pedidos desde cualquier dispositivo con conexión a Internet.
