Acerca de REATS

REATS es una aplicación web diseñada para consultar platillos, registrar pedidos y facilitar la administración de información relacionada con los clientes.

La aplicación permite seleccionar un platillo, registrar los datos del cliente y obtener su ubicación mediante un mapa.

REATS fue desarrollada como un proyecto académico utilizando tecnologías web modernas.
