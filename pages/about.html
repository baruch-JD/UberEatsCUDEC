Acerca de REATS

REATS es una aplicación web diseñada para consultar platillos y registrar pedidos.

La aplicación permite seleccionar platillos, registrar los datos del cliente y obtener su ubicación mediante un mapa.

REATS fue desarrollada como un proyecto académico utilizando tecnologías web.
